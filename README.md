# student-finance-tracker
Accessible, responsive student finance tracker built with vanilla HTML, CSS and JS.
Live site: https://mnoah10.github.io/student-finance-tracker/
Run a local web server from the project folder, for example:

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000` in a modern browser. Serving the files over
HTTP allows the browser to load the JavaScript modules correctly. Records and
settings are saved in browser local storage. You can add, edit, delete, search,
and sort spending records, set a spending cap and display currencies, and
import or export the tracker data as JSON.
